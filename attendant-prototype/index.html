Attendant app

Route + attendance - clickable prototype built from the 7 Figma frames.

Try: tap the number field and type a 10-digit number (start with 6-9), Submit, START ROUTE on the pick-up card, Details on a stop, the toggles, View Parent Details on Michael, then Submit.

The Figma flow has no login OTP for attendants, and no designs for Ended Trip, the drop-off route, the menu or calling. Submit opens a confirmation screen (added after the Figma flow, built from the same tokens) that counts down and returns to the route listing. After START ROUTE the trip moves from "not started" to "on the way" by itself after a few seconds (prototype only).
